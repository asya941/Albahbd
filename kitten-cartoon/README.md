# 🐱 Рыжик в волшебном лесу

Короткий 2D-мультфильм (≈20 секунд) о маленьком рыжем котёнке, который гуляет по волшебному лесу.
Сделан на **HTML + CSS + JavaScript + SVG**, без библиотек и без сборки.

## Что есть в мультфильме
- Котёнок идёт с настоящим циклом шага: лапки двигаются диагональными парами и приподнимаются, тело покачивается, лапы не «скользят» по земле.
- Моргание, подёргивание ушей, качание хвоста, шевеление усов, глаза следят за бабочкой.
- Падающие листья, которые кружатся и переворачиваются; светлячки; мерцающие звёзды; лучи света.
- Многослойный фон с параллаксом: холмы, сиреневые дальние деревья, разноцветные кроны, светящиеся грибочки, цветы, трава на ветру, папоротники на переднем плане.
- Сюжет: титр → прогулка → прилетает бабочка → котёнок идёт дальше → «Мяу!» → «Конец».
- Автозапуск, пауза, перемотка, кнопка «Смотреть ещё раз», полноэкранный режим.

## Как посмотреть на Samsung Galaxy Tab S8 Ultra
1. Скачайте папку `kitten-cartoon` на планшет (на GitHub: **Code → Download ZIP**, затем распакуйте в «Мои файлы»).
2. Откройте приложение **«Мои файлы»**, найдите `kitten-cartoon/index.html` и нажмите на него → выберите **Samsung Internet** или **Chrome**.
3. Поверните планшет **горизонтально** — сцена сделана в пропорции 16:10, как экран Tab S8 Ultra.
4. Нажмите кнопку **⛶** — мультфильм откроется на весь экран.

Мультфильм запускается сам. Управление:
- **тап по экрану** или **❚❚ / ▶** — пауза / продолжить;
- **↻** — смотреть сначала; в конце появляется большая кнопка «Смотреть ещё раз»;
- **полоса прогресса** — перемотка (нажмите в нужное место).

Можно также опубликовать через **GitHub Pages** (Settings → Pages → выбрать ветку) и открыть ссылку
`https://<ваш-логин>.github.io/<репозиторий>/kitten-cartoon/` прямо в браузере планшета.

## Как посмотреть на компьютере
- Просто дважды щёлкните `index.html` — он откроется в браузере.
- Или запустите локальный сервер в папке проекта:
  ```bash
  cd kitten-cartoon
  python3 -m http.server 8000
  ```
  и откройте `http://localhost:8000`.

Клавиши: **Пробел** — пауза, **R** — повтор, **F** — полный экран.
Для отладки можно начать с нужной секунды: `index.html?t=9`.

> Шрифт Comfortaa загружается из Google Fonts. Без интернета мультфильм тоже работает — используется системный шрифт.
